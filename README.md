# MoneyFesting

MoneyFesting is a full-stack paper trading platform inspired by modern stock trading applications.

## Project Goal

The platform will simulate stock trading and provide features such as:

- User authentication
- Marketwatch
- Stock details
- Buy and sell orders
- Holdings
- Positions
- Funds
- Portfolio
- Profit & Loss
- Simulated real-time market prices

## Technology Stack

### Frontend
- React.js

### Backend
- Java
- Spring Boot

### Database
- MySQL

### Other Technologies
- JWT Authentication
- REST APIs
- WebSocket
- Git & GitHub
